# PATTERN ROOM

패턴과 오브젝트의 시각적 관계를 실험하는 한국어 인터랙티브 3D 스튜디오입니다. React, TypeScript, Three.js, Vite를 사용합니다.

## 실행

Node.js 22.12 이상 또는 24 LTS를 사용합니다.

```sh
npm ci
npm run dev
```

개발 서버는 기본 포트 5173에서 실행됩니다.

```sh
npm run build   # TypeScript 검사와 프로덕션 빌드
npm run preview # 빌드 결과 실행
npm test        # Playwright 브라우저 테스트
```

브라우저 테스트 환경에서는 먼저 `npx playwright install chromium`으로 Chromium을 준비합니다. WebGL을 지원하는 최신 데스크톱 브라우저를 권장합니다.

## 실험하기

1. 기본 패턴을 고르거나 PNG·JPG·WEBP·SVG 이미지를 업로드합니다. 업로드한 이미지는 **내 패턴** 목록에 남으며, 기본 패턴처럼 다시 선택해 사용할 수 있습니다.
2. 두 벽을 함께 편집하거나 연결을 해제해 벽마다 다른 패턴을 적용합니다.
3. 패턴 크기·반복 수·회전·명도·채도·불투명도·벽 기본색을 조절합니다.
4. 화병·구·정육면체·링·추상 조각을 선택하거나 직접 만든 GLB 모델을 올립니다.
5. A와 B에 실험 상태를 저장해 비교하고 메모를 기록합니다.
6. 패턴 비교 모드에서는 오브젝트·조명·카메라를 같은 조건으로 유지합니다.
7. PNG로 현재 장면 또는 나란히 놓인 비교 장면을 저장합니다.

드래그하면 시점이 회전하고 휠·트랙패드로 확대·축소할 수 있습니다. 카메라 프리셋, 시점 잠금과 초기화, 패널을 숨기는 집중 보기도 제공합니다.

## 공간과 파일

방은 **5 × 5 × 5**, 중앙 좌대는 **1 × 1 × 2.5**입니다. 좌대는 바닥 중앙에 있으며 윗면은 벽 높이의 정확히 절반입니다. 정면·오른쪽 벽과 천장은 시야와 빛을 가리지 않도록 열려 있습니다. 오브젝트는 실제 경계를 기준으로 좌대 중앙과 윗면에 정렬됩니다.

- 패턴 이미지: 최대 **20MB**, 한 변 최대 **16,384픽셀**. SVG는 외부 참조·스크립트·애니메이션이 없는 정적인 이미지여야 합니다.
- 모델: 최대 **50MB**, 텍스처와 버퍼를 포함한 **GLB 2.0**. Draco·Meshopt·KTX2 압축은 지원하지 않습니다.
- 업로드 모델은 원래 재질을 유지하며 좌대에 맞는 크기로 조정됩니다.

## 상태와 개인정보

실험 상태, A/B 스냅샷, 메모, 업로드한 이미지와 모델은 **현재 브라우저의 IndexedDB**에 저장됩니다. 조절 직후 새로고침해도 최신 상태를 복원할 수 있도록, 파일 자체를 제외한 작은 상태 정보는 localStorage에도 즉시 백업합니다. 파일은 서버로 업로드하지 않습니다. 다른 브라우저나 기기에 자동으로 동기화되지 않으며, 사이트 데이터 삭제·시크릿 모드 종료·브라우저 저장 공간 정리 시 작업이 삭제될 수 있습니다.

업로드한 패턴은 **내 패턴**에 최근 업로드 순으로 보관됩니다. 다른 패턴으로 바꾸거나 새로고침해도 남아 있으며, 썸네일을 선택하면 현재 선택한 벽에 다시 적용할 수 있습니다. 목록에서 패턴을 삭제해도 현재 장면이나 A/B 기록에서 사용 중인 이미지는 해당 실험이 유지되는 동안 보존됩니다. **전체 초기화**는 현재 작업·A/B 기록·업로드 모델을 지우고 기본 장면으로 돌아가지만, 내 패턴 목록은 유지합니다. 내 패턴의 파일까지 지우려면 목록에서 직접 삭제하거나 브라우저의 사이트 데이터를 삭제하세요.

외부 API 키, 데이터베이스 서버, 로그인은 필요하지 않습니다. 이 클라우드 작업은 이미 격리된 환경이므로 기존 체크아웃에서 작업하며 별도의 Git worktree를 만들 필요가 없습니다.
